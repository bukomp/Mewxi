## kanbu

This repo is kanbu project `MEW` on https://kanbu.void0.one. Take and update its tickets
with the kanbu MCP tools: the server's instructions hold the working protocol.
Work in dispatcher mode, as "Dispatcher mode" in the server's instructions
says: hand each ticket to its own sub-agent in a git worktree under
`.worktrees/`, and never do ticket work yourself.
